# Clínica del PC: prototipo

Prototipo de interfaz del sistema de recepción y seguimiento de equipos de la Clínica del PC (Ingeniería de Software, INACAP). Corre solo en el navegador con datos de ejemplo en memoria, sin servidor ni base de datos.

## Cómo correrlo

```
npm install
npm run dev
```

## Accesos de prueba

- Técnico: `l.reyes1` / `1234`
- Admin: `pesce` / `1234`
- Portal de clientes: RUT `21044735-0` o `19123456-7`
- Recepción: acceso directo desde la pantalla inicial
